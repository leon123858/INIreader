# INIreader

A modern, fast, and lightweight INI file editor built with Wails and React.

## Features
- Structured, section-based UI
- Auto-saves changes
- Clean and intuitive design

## Download and Installation

You can download the latest release from the [Releases](../../releases) page. We provide two formats:
1. **MSI Installer (`.msi`)**: Recommended. It will automatically install the application and associate `.ini` files with INIreader so you can double-click them to open.
2. **Standalone Executable (`.exe`)**: Portable version. You can place it anywhere and run it without installation.

### Manually Associating `.ini` Files (For Standalone `.exe` users)

If you chose to download the standalone `.exe` and want to open `.ini` files by double-clicking them, follow these steps in Windows:
1. Right-click on any `.ini` file.
2. Select **Open with** -> **Choose another app**.
3. Scroll down and check the box that says **Always use this app to open .ini files**.
4. Click **Look for another app on this PC** (you might need to click "More apps" first to see this option).
5. Browse to the folder where you saved `INIreader.exe`, select it, and click **Open**.

Now, all `.ini` files will automatically open with INIreader.
